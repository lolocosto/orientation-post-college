# v0.59 — Phase 4 : Refactoring `carif_oref_extraction_controller.js`

## Principe directeur

Même principe que la phase 3 (Onisep) : la logique métier de fusion établissement scolaire/apprentissage est **déplacée du DatabaseService vers le contrôleur CARIF**. Le DatabaseService reste un stockage "bête".

---

## Changements

### 1. Nouvelle méthode `#fusionnerOuInsererEtablissement(etabCarif)` → string|null

Logique de fusion déplacée depuis `DatabaseService.fusionnerEtablissementAprentissage()` :

1. **Match UAI + nom normalisé** → enrichir l'existant + ajouter voie 'apprentissage'
2. **Un seul existant avec cet UAI** (pas de match nom) → enrichir par défaut
3. **Plusieurs existants, aucun match nom** → nouvel enregistrement (structure différente)
4. **Aucun existant** → nouvel enregistrement via `insertEtablissement()`

L'enrichissement utilise `updateEtablissement()` (phase 1) qui est non-destructif par défaut : les champs ONISEP déjà renseignés ne sont pas écrasés. Les voies sont fusionnées (union).

### 2. Deux appels remplacés

| Flux | Avant | Après |
|---|---|---|
| `#extractEtabsEtDiplomesByCommunes` (geo) | `this.#databaseService.fusionnerEtablissementAprentissage(e)` | `this.#fusionnerOuInsererEtablissement(e)` |
| `#extractEtabsEtDiplomesByUAIs` (diplômes) | idem | idem |

### 3. Résolution etabId dans `#storeDiplomes` — inchangée

La résolution UAI+nom → etabId (lignes 581-593) était déjà correcte :
- Recherche exacte `getEtablissementByUaiSync(uai, nom)` si `etabNom` disponible
- Fallback `getEtablissementsByUaiSync(uai)[0]` sinon

### 4. `#extractAutresFormationsNiveau5Plus` — inchangée

Résolution par UAI seul vers tous les étabs (`getEtablissementsByUaiSync`). C'est sémantiquement correct : les formations niveau 5+ sont partagées par site physique (identifié par UAI).

---

## Méthodes inchangées

`#extractEtabsEtDiplomesByCommunes` (flux principal), `#extractDiplomesByUAIs`, `#parseEtStoreDiplomesDepuisFormations`, `#storeDiplomes`, `#extractAutresFormationsNiveau5Plus`, `#resetAprentissageData`, tous les méthodes publiques (`extractByGeo`, `extractByDiplomesLibelles`, etc.)

---

## Impact

- Le **wrapper deprecated** `DatabaseService.fusionnerEtablissementAprentissage()` n'est plus appelé par ce contrôleur. Il reste disponible pour d'éventuels autres appelants, mais pourra être supprimé à terme.
- Ce fichier **dépend** de la phase 1 (`updateEtablissement()` non-destructif, `insertEtablissement()` avec validation stricte).
- Le parser CARIF (`carif_oref_parser.js`) n'est **pas modifié** — il portait déjà `etabNom` dans les relations.
