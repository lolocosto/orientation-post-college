# v0.59 — Phase 1 : Refactoring `database_service.js`

## Principe directeur

**Le `DatabaseService` est un service de stockage "bête"** : il valide les champs obligatoires, gère l'unicité, stocke et restitue. Il ne prend aucune décision métier (voies à initialiser, fusion de données entre sources, etc.). C'est au contrôleur de préparer les données correctement avant insertion.

---

## Changements

### 1. `insertEtablissement()` — RÉÉCRIT

**Avant** : Prenait des décisions métier (initialisation des voies, migration des noms, fusion des doublons avec merge des voies).

**Après** : Validation stricte + stockage simple.
- **Refuse** si : pas d'UAI ni SIRET, pas de nom (nomOnisep/nomCarif), pas de voies (tableau vide ou absent)
- **En cas de doublon** (même clé d'unicité) : retourne l'_id existant **sans modifier** les données en base
- **Initialise le champ `nom`** (affichage UI) : priorité nomOnisep pour scolaire, nomCarif pour apprentissage
- Ne fusionne plus les voies, ne décide plus de la voie par défaut

### 2. `getEtabIdByUaiNom(uai, nom)` — NOUVELLE MÉTHODE

Lookup pur : recherche un _id par la clé d'unicité (UAI+nom normalisé). Retourne `null` si pas trouvé. Ne crée rien.

### 3. `updateEtablissement(id, updates, options)` — AMÉLIORÉ

**Avant** : Simple `Object.assign` destructif.

**Après** : Enrichissement non-destructif par défaut.
- Ne remplace que les champs `null`/`undefined`/`''` dans l'existant
- **Voies** : fusion (union) sans doublons, jamais de suppression
- **Option `overwrite: true`** : écrase systématiquement tous les champs
- Recalcule le nom d'affichage si nomOnisep/nomCarif changent
- Retourne `boolean` (trouvé et mis à jour ou non)
- ⚠️ Devenu synchrone (mais `await` sur une valeur sync = no-op, pas de casse)

### 4. `getLanguesParEtablissement(etabId)` — DOCUMENTÉ

La jointure par UAI est **sémantiquement correcte** pour les langues : elles sont liées au site physique (identifié par UAI), pas à une structure administrative. Ajout d'un commentaire explicatif.

### 5. Fonctions mortes supprimées (section E de l'audit)

| Fonction | Raison |

| `lireEtablissements()` | Aucun appelant externe |
| `lireEtablissementsAsync()` | Wrapper inutile de lireEtablissements |

| `enrichirEtablissement()` | Remplacée par `updateEtablissement()` |

## Bug pré-existant identifié

`data_education_extraction_controller.js:304` :
```js
await this.#databaseService.updateEtablissement(infos.uai, infos);
```
Passe un **UAI** comme premier argument au lieu d'un **_id**. L'ancien code faisait un `Object.assign` silencieux sur `undefined`. Le nouveau code retourne `false` et log un warning. **À corriger dans une phase ultérieure.**
